# 画像と言葉の指示で動く片付けロボット

Physical AI 講座の最終課題向けに、既存の OpenVLA-OFT ロボット実行記録から8例だけを選び、字幕を付ける前の映像と最小実行コードをまとめた独立リポジトリです。

追加学習済みモデル `mixed_000500` が、カメラ画像・言語指示・ロボット状態を受け取り、アームとグリッパの動作を出力した記録です。食品をかごに入れる、ボウルを移す、引き出しに収納する成功例7本（45秒）と、目標を達成できなかった例1本（15秒）を収録します。

これは選抜した事例紹介です。7/8を全体の成功率として扱いません。元の競技の総合スコアを再現するパッケージでもありません。

## まず動画を編集する

生成済みの字幕なしマスターと個別クリップは `media/output/` と `media/edit/` にあります。DaVinci Resolveへの取り込み手順は [編集ガイド](docs/editing.md) を参照してください。

元の映像は各視点128×128、20fpsです。全体視点と手元視点を1080pキャンバスに配置してありますが、元映像の細部を増やす処理はしていません。完成品のフレームレートは30fpsで、元のシミュレーション時間に沿って再生します。元録画には推論待ちの実時間は含まれません。

再生成用の軽い環境は Windows / macOS / Linux で利用できます。

```sh
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS / Linux: source .venv/bin/activate
python -m pip install -e ".[video]"
python scripts/build_video.py
python scripts/verify_video.py
```

出力は `media/output/pai_demo_no_subtitles.mp4`（約80秒）です。字幕・音声は焼き込んでいません。生成済みファイルはGit対象外で、選定した原本16本（8例×2視点）と編集スクリプトをGitで管理します。

## 再現できる範囲

| 操作 | このリポジトリに含むもの | 別途必要なもの |
|---|---|---|
| 字幕なし動画の再編集 | 原本映像、編集コード、タイムライン | PythonとFFmpeg。GPU不要 |
| 保存行動のシミュレータ再生 | 8例の初期状態・行動・参照関節軌道、再生コード | 公開LIBERO-plus環境と対応アセット |
| AIによる新規推論 | 最小の推論・実行・録画コード | OpenVLA-OFT環境、利用可能な学習済み重み、GPU |

**保存行動の再生は、新規AI推論とは別です。** 同一モデルで推論をやり直すには、収録時の追加学習済み重みが必要です。その重みは本リポジトリに含みません。公開ベースモデルに置き換えた場合、動作や成功判定も変わり得ます。

ロボット実行環境はLinux / Python 3.10を想定し、動画編集用venvとは分けてください。セットアップ・実行例・検証範囲は [再実行手順](docs/reproduction.md) に記載します。

## 構成

```text
pai-final-demo/
  src/pai_demo/          最小のロボット再生・推論コード
  scripts/              動画編集・検証コマンド
  data/manifest.json    選定8例の一覧
  data/episodes/        初期状態・行動・必要な実行条件
  media/source/         選定8例×2視点の原本MP4
  media/edit/           Resolve用の個別クリップ（生成物）
  media/output/         字幕なしマスターと検査結果（生成物）
  docs/                 編集・再実行・出自・検証の記録
```

## このフォルダだけを公開する

Git履歴はこのサブフォルダで新規作成しています。元プロジェクトの履歴・資料・評価システム・全データ・モデル重みは含みません。リポジトリ全体への参照や元の非公開リモートも設定していません。

GitHubに公開する際はこのフォルダをリポジトリのルートにしてください。`media/output/` などの生成物を除外しても、追跡対象の原本から再編集できます。YouTubeへ提出するのは、Resolveで字幕を加えた最終MP4です。
