# LIBERO-PlusにおけるOpenVLA-OFTの物体操作デモ

カメラ画像・言語指示・ロボット状態からアームとグリッパを動かす、OpenVLA-OFTの実行事例をまとめたリポジトリです。Physical AI講座の最終課題として、追加学習済みモデル `mixed_000500` の記録から8エピソードを選び、原本映像・動作データ・動画編集スクリプト・最小の再生／推論コードを収録しています。

環境は **LIBERO-Plusの公開タスク** です。モデルは公開OpenVLA-OFT+を出発点に追加学習したもので、学習経緯は [モデルと学習条件](docs/model.md) に記載しています。

食品をかごに入れる、ボウルを移す、引き出しに収納する成功例7本（45秒）と、目標未達の例1本（15秒）を収録しています。説明のために選んだ事例であり、7/8はモデル全体の成功率を示しません。

## 取得後のファイル確認

Python 3.10以降で、リポジトリのルートから実行します。

```sh
python scripts/check_repository.py
```

追加パッケージなしで、必要なファイル・8件の動作データ・16本の原本映像・ハッシュ・文書内のローカルリンクを検査します。Git cloneだけでなく、ZIP展開やファイルコピー後の欠落確認にも利用できます。`PASS` は配布ファイルの整合性を示し、外部のシミュレータやモデルの動作を保証するものではありません。

## 字幕なし動画の再生成

Windows / macOS / Linuxで、動画用のPython環境を用意します。

```sh
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS / Linux: source .venv/bin/activate
python -m pip install -e ".[video]"
python scripts/build_video.py
python scripts/verify_video.py
```

出力は `media/output/pai_demo_no_subtitles.mp4`（約80秒、1920×1080、30fps）です。動作映像60秒に、冒頭・末尾の静止画各10秒を加えます。初回の依存パッケージ取得にはネットワーク接続が必要ですが、動画生成にGPUやシミュレータは不要です。

元の映像は各視点128×128、20fpsです。全体視点と手元視点を拡大して配置しますが、元映像の細部を増やす処理はしません。録画はシミュレーション時間に沿っており、AIの推論待ち時間は含まれません。

> **注記：** `media/edit/` と `media/output/` は生成物のため、取得直後には存在しません。原本16本と編集コードから上記手順で生成します。字幕・音声を加えた完成版動画、字幕ファイル、DaVinci Resolveのプロジェクトファイルは同梱していません。個別クリップの利用方法は [編集ガイド](docs/editing.md) を参照してください。

## 再現できる範囲

| 操作 | このリポジトリに含むもの | 別途必要なもの |
|---|---|---|
| 収録データの確認 | 映像、行動配列、実行条件、検査コード | Python。映像視聴にはMP4対応プレーヤー |
| 字幕なし動画の再編集 | 原本映像、編集コード、タイムライン | PythonとFFmpeg。GPU不要 |
| 保存行動のシミュレータ再生 | 8例の初期状態・行動・参照関節軌道、再生コード | LIBERO-plus、タスク定義、対応アセット、物理・描画環境 |
| AIによる新規推論 | 公開OFT API用の推論アダプターと実行・録画コード | 上記環境、OpenVLA-OFT、互換モデルの重み・各ヘッド、GPU |
| 学習条件の確認 | 学習経緯、設定、照合用ハッシュ | 同一モデルの再学習には訓練データ・元の学習コードと環境・重みが別途必要 |

> **注記：** 収録時の追加学習済み重み、訓練データ一式、元の学習・モデル配備環境は同梱していません。本リポジトリだけで同一モデルを再学習したり、同一のAI推論を再実行したりすることはできません。公開ベースモデルへ置き換えた場合、動作や成功判定も変わり得ます。保存行動の再生では新たなAI推論を行いません。

ロボット実行環境はLinux / Python 3.10を想定し、動画編集用venvとは分けてください。`pip install -e .` だけではシミュレータやGPU関連の依存は揃いません。セットアップ・実行例は [再実行手順](docs/reproduction.md) に記載しています。本リポジトリのランタイムによる実シミュレータ上の物理再生とGPU推論は未検証です。

## 構成

```text
pai-final-demo/
  src/pai_demo/          最小のロボット再生・推論コード
  scripts/              動画編集・検証コマンド
  data/manifest.json    選定8例の一覧
  data/model_training.json  学習条件の記録
  data/task_sources.json    公開タスクの出典・参照版・ハッシュ
  data/episodes/        初期状態・行動・必要な実行条件
  media/source/         選定8例×2視点の原本MP4
  media/edit/           Resolve用の個別クリップ（生成物）
  media/output/         字幕なしマスターと検査結果（生成物）
  docs/                 編集・再実行・出自・検証の記録
```
