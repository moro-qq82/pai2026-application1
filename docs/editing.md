# 映像の再生成と編集

このリポジトリには、8エピソード分の原本映像と、2視点を配置して連結するスクリプトを収録しています。字幕なしマスターと個別編集クリップは生成物のため、Gitから取得した直後には存在しません。

> **注記：** 字幕・音声を加えた完成版動画、字幕ファイル、DaVinci Resolveのプロジェクトファイルは含まれません。以下の手順では、収録済みのロボット実行映像から字幕なし動画を生成します。シミュレータやAIモデルの実行環境は不要です。

## 字幕なし動画を生成する

Python 3.10以降の環境を用意し、リポジトリのルートで実行します。

```sh
python -m pip install -r requirements-video.txt
python scripts/build_video.py
python scripts/verify_video.py
```

`requirements-video.txt` はFFmpegの取得・検出用のimageio-ffmpegと、検査画像の作成用のPillowを導入します。依存パッケージの初回取得にはネットワーク接続が必要です。

FFmpegの場所を明示する場合は両コマンドに `--ffmpeg /path/to/ffmpeg` を付けます。FFmpegは、明示したパス、PATH、imageio-ffmpegの順に検出します。

出力は `media/output/pai_demo_no_subtitles.mp4` です。1920×1080、30fps、H.264 / yuv420p、音声なしで、長さは約80秒です。動作部分は約60秒、冒頭と末尾の静止画は各10秒です。

再生成は `media/edit/` と `media/output/` の同名ファイルを上書きします。編集ソフトで書き出す完成版は別名・別フォルダに保存してください。

## DaVinci Resolveでの編集例

1. Resolveで新規プロジェクトを作り、タイムラインを1920×1080・30fpsに設定します。
2. 生成した `media/output/pai_demo_no_subtitles.mp4` を取り込み、タイムラインへ置きます。
3. 冒頭10秒、動作中の各場面、末尾10秒へ必要な字幕・説明を追加します。
4. H.264のMP4で書き出します。

元の128×128映像を拡大して配置しているため、細部の精細さには限界があります。左が全体視点、右が手元視点です。上側と下側に文字用の余白があり、下側は概ねY=920〜1040が字幕領域です。画面の位置や大きさを変えたい場合は、次の個別クリップまたは `media/source/` の原本を使えます。

## 個別に編集する場合

`media/edit/` に以下を生成します。

- `00_intro.mp4`：最初の場面の静止画、10秒
- `01_*.mp4`〜`08_*.mp4`：成功7例、失敗1例の全体・手元を配置した個別クリップ
- `99_outro.mp4`：最後の成功例の静止画、10秒
- `timeline.csv` / `timeline.json`：順番、各場面の日本語名、開始・終了時刻

冒頭と末尾はタイトルなどを置くための静止画です。実行が停止した映像や追加の成功試行を意味しません。

タイムライン表の `end_timecode_exclusive` は、最後のフレームの次の時刻です。時刻はクリップの先頭を `00:00:00:00` とした30fpsの相対値です。Resolve側が `01:00:00:00` 始まりの場合は1時間分を足してください。CSVは参照表であり、Resolveのタイムラインを直接インポートする形式ではありません。

初回生成時の参照用タイムラインを [edit_timeline.csv](edit_timeline.csv) に収録しています。再生成後の時刻は `media/edit/timeline.csv` で確認できます。

## 表示する内容の事実関係

- タスクはLIBERO-Plusの公開タスクです。モデルは追加学習済みのOpenVLA-OFT `mixed_000500` です。
- 最初の7本は元ログで目標達成、最後の1本は目標未達です。順番とタスク名はタイムライン表のとおりです。
- 7/8は選定した事例の内訳で、モデル全体の成功率ではありません。
- 収録時のAIへの入力はカメラ画像・言語指示・ロボット状態です。映像の再編集では、新しいAI推論は行いません。
- 再生はシミュレーション時間に沿っており、モデルが推論を待つ実時間は省かれています。動画の長さは実際の推論所要時間を示しません。
- 元の記録は各行動の直前の映像なので、最後の成功判定直後の状態が映像に含まれない場合があります。成否の根拠は保存ログです。

収録データの出自は [provenance.md](provenance.md)、モデルの学習経緯は [model.md](model.md) を参照してください。
