# タスクとモデルの学習条件

## タスクの出典

収録した8エピソードは、7種類の **LIBERO-Plusの公開タスク定義** を使用しています。LIBEROの物体操作タスクに照明や背景テクスチャの変化を加えた条件です。本プロジェクト独自のタスク定義ではありません。

各エピソードのBDDLハッシュは、[LIBERO-plusの固定コミット](https://github.com/sylvestf/LIBERO-plus/tree/4976dc30028e805ff8094b55501d532c48fec182) にある対応ファイルと照合済みです。ファイルごとの公開URL・SHA-256・対応エピソードは [task_sources.json](../data/task_sources.json) に収録しています。

> **注記：** BDDL本体、シミュレータ、シーンアセットは同梱していません。保存行動を物理再生する場合は、[再実行手順](reproduction.md) に従って外部の配布物を取得してください。

## 学習の経緯

映像に使用したモデルは `OpenVLA-OFT mixed_000500` です。公開モデルからの追加学習は、次の2段階で行われました。

1. 公開の [OpenVLA-OFT+](https://huggingface.co/Sylvest/openvla-7b-oft-finetuned-libero-plus-mixdata) を出発点に、[LIBERO-Plusの公開RLDSデータ](https://huggingface.co/datasets/Sylvest/libero_plus_rlds)（14,347軌道）を使って4,000 optimizer updatesの追加学習を行いました。公開モデルのチェックポイント表記150,000に対し、この時点の表記は154,000です。
2. そのモデルを基に、公開データと新規に収集したデータを混ぜ、新しいLoRAを500 optimizer updates学習したチェックポイントを使用しました。これが `mixed_000500` で、書き出し時の表記は154,500です。

したがって「154,500」は、独自に154,500回学習したことを意味しません。第2段階は1,000 updatesの実行計画に対し、途中の500 updates時点のモデルです。

## 第2段階の追加学習

| 項目 | 設定・記録 |
|---|---|
| 学習方法 | 連続行動をL1損失で学習する教師あり模倣学習 |
| 入力 | 2視点のカメラ画像、言語指示、8次元のロボット状態 |
| 出力 | 7次元の行動を8ステップ分まとめたaction chunk |
| 更新対象 | LoRA、action head、proprio projector |
| LoRA | rank 32、alpha 16、dropout 0 |
| Optimizer | AdamW、学習率 `1e-5`、weight decay `0.01` |
| Batch | 1、勾配累積8（1 updateあたり8サンプル） |
| 混合比 | 公開データ80%・新規データ20% |
| 使用チェックポイント | 500 updates、seed 1000 |

新規データは1,000軌道で、照明変化500軌道と背景テクスチャ変化500軌道からなります。教師の内訳は、シミュレータの内部状態を利用するexpert controllerによる900軌道と、OpenVLA教師モデルによる100軌道です。追加データの収集方法と、最終モデルが受け取る入力は区別してください。

500 updatesまでの記録では、学習に投入したサンプルは公開データ3,200件・新規データ800件の計4,000件です。ここでの「サンプル」は学習時の入力単位であり、軌道数ではありません。新規1,000軌道をすべて1周学習した、という意味でもありません。

設定と照合用ハッシュは、元の学習・書き出し記録から必要な項目を抽出した [model_training.json](../data/model_training.json) に記載しています。このファイルは学習内容の記録であり、学習を実行する設定ファイルではありません。

## 配布範囲と解釈上の制約

> **注記：** 収録時の追加学習済み重み・LoRA adapter・各ヘッド、訓練データ一式と完全なデータ選択表、元のデータ生成・学習・モデル配備コードと実行環境は同梱していません。公開元のベースモデルと本リポジトリの設定記録だけでは、収録モデルを厳密に復元できません。照合用ハッシュから欠けているファイルを復元することもできません。

本リポジトリの `infer` は、公開OpenVLA-OFT APIを利用する最小アダプターです。収録時のモデル配備環境そのものではなく、互換モデルの重みを別途用意する必要があります。`replay` は収録済み行動の再生で、新たなモデル推論は行いません。

8件の動画は説明用の選抜例です。この動画だけから、追加学習による性能向上や、LIBERO-Plus全体での成功率を結論づけることはできません。記録の意味と検証範囲は [出自](provenance.md) と [検証記録](validation.md) を参照してください。
