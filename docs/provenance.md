# 映像・データの出自と再現範囲

このリポジトリは、追加学習済みOpenVLA-OFTによるロボット実行記録から、8エピソードを選んで収録したものです。公開する範囲は、選定した映像・行動データと、その再編集・再生・検証に用いるコードです。

## タスクとモデル

収録した8エピソードは、7種類のLIBERO-Plus公開タスク定義を使用しています。タスク定義のSHA-256は、公開LIBERO-Plusの固定コミット `4976dc30028e805ff8094b55501d532c48fec182` の対応ファイルと一致することを確認しています。LIBEROの物体操作タスクに照明や背景テクスチャの変更を加えた条件であり、本プロジェクト独自のタスク定義ではありません。

モデルは、公開OpenVLA-OFT+を出発点として追加学習した `mixed_000500` です。学習条件と独自に追加したデータについては [model.md](model.md) に記載しています。

## 含めるもの

- `media/source/<case_id>/`：各エピソードの全体視点 `agentview.mp4` と手元視点 `wrist.mp4`。元の録画ファイルを変更せず複製しています。
- `data/episodes/<case_id>/trajectory.npz`：記録済みの行動 `actions`、初期物理状態 `initial_state`、行動前後の関節角 `pre_joint` / `post_joint` のみ。
- `data/episodes/<case_id>/metadata.json`：指示、公開 BDDL ファイルの相対参照と SHA-256、乱数 seed、初期化手順、元の成功判定、元映像の SHA-256。
- `data/manifest.json`：編集順、各クリップの秒数、データと映像の照合用 SHA-256。
- `data/task_sources.json`：公開タスク定義のURL、参照コミット、SHA-256と対応エピソード。
- `data/model_training.json`：学習・書き出し記録から抽出した学習条件と照合用ハッシュ。

抽出時に、初期状態のバイト列ハッシュと元の計画記録、行動数と実行step数、映像のSHA-256と元の実行記録が一致することを確認しています。NPZは選定エピソードの再生と関節軌道の照合に必要な数値配列を収録します。

## AI の実行映像と行動再生の区別

元の映像は `OpenVLA-OFT mixed_000500` が観測を受け取り、行動を返してシミュレータを動かした時の記録です。映像の編集・連結や、保存済み `actions` の物理再生は、新しいAI推論を行いません。ランタイムの `replay` は保存行動の再生、`infer` は別途用意したモデルによる新規推論です。

> **注記：** 収録に使用した追加学習済みモデルの重みと元のモデル配備環境は配布物に含まれません。`data/manifest.json` の `source_model_identity_sha256` はモデル同一性の照合用であり、このハッシュだけからモデルを復元することはできません。公開モデルへ置き換えた推論が、元の動画と同じ出力になる保証はありません。

## 時間・画質・フレームの扱い

- 元映像は各視点 128 x 128、20 fps です。AI が推論を待っていた実時間は動画に含まれず、1 action を 1 frame としてシミュレーション時間に沿って保存されています。
- 行動は20Hzで実行されました。元の各映像の秒数は `steps / 20` です。映像の再生速度は、実際の推論速度を示すものではありません。
- 元映像には生のカメラ観測を 180 度回転して見やすくしたものが保存されています。推論入力の画像を編集したものではありません。
- 各 frame は行動直前の画像です。最後の行動の結果は成功ログに記録されていても、最後の映像 frame にはまだ映っていない場合があります。
- 出力の拡大・2視点配置・フレームレート変換は編集上の処理です。低解像度の細部を新しく生成する処理は行いません。

## 公開依存と再現の限界

> **注記：** シミュレータのソース、シーン定義、アセットは別途取得が必要です。参照する公開プロジェクトは以下のとおりです。

- [LIBERO-plus](https://github.com/sylvestf/LIBERO-plus)：元環境の固定コミット `4976dc30028e805ff8094b55501d532c48fec182`。
- [LIBERO](https://github.com/Lifelong-Robot-Learning/LIBERO)：元環境が参照したコミット `8f1084e3132a39270c3a13ebe37270a43ece2a01`。
- [OpenVLA-OFT](https://github.com/moojink/openvla-oft)：公開のモデル実装と導入手順。

物理状態は環境の内部配列です。物理エンジン・シーン・コントローラー・初期化手順が異なると、同じ行動でも異なる軌道になる場合があります。ランタイムは保存した関節角と再生時の関節角を比較し、軌道の一致を報告します。

本リポジトリのランタイムによる実シミュレータ上の物理再生とGPU推論は未検証です。実施済みのデータ検査・動画再生成・制御フローテストは [validation.md](validation.md) に記載しています。
