# 映像・データの出自と再現範囲

このリポジトリは、実施済みの OpenVLA-OFT ロボット評価から選んだ 8 エピソードを、講座の説明動画と小さな再現用パッケージにまとめたものです。元の限定公開リポジトリ、配布評価基盤、全体の実験結果は含めません。

## 含めるもの

- `media/source/<case_id>/`：各エピソードの全体視点 `agentview.mp4` と手元視点 `wrist.mp4`。元の録画ファイルを変更せず複製しています。
- `data/episodes/<case_id>/trajectory.npz`：記録済みの行動 `actions`、初期物理状態 `initial_state`、行動前後の関節角 `pre_joint` / `post_joint` のみ。
- `data/episodes/<case_id>/metadata.json`：指示、公開 BDDL ファイルの相対参照と SHA-256、乱数 seed、初期化手順、元の成功判定、元映像の SHA-256。
- `data/manifest.json`：編集順、各クリップの秒数、データと映像の照合用 SHA-256。

各データを抽出する際に、初期状態のバイト列ハッシュと元の計画記録、行動数と実行 step 数、映像の SHA-256 と元の実行記録が一致することを確認しています。抽出した NPZ には実験全体の物体履歴、元サーバーのパス、個人情報を含む文字列は保存していません。

## AI の実行映像と行動再生の区別

元の映像は `OpenVLA-OFT mixed_000500` が観測を受け取り、行動を返してシミュレータを動かした時の記録です。映像の編集・連結や、保存済み `actions` の物理再生は、新しい AI 推論を行いません。発表時は「既存のモデル実行記録」「記録済み行動の再生」「新しくモデルを推論して実行」を区別してください。

元モデルは追加学習後のチェックポイントです。同じモデルの重みはこのリポジトリに含めません。モデル同一性の照合には `data/manifest.json` の `source_model_identity_sha256` を使用できますが、このハッシュだけからモデルを復元することはできません。公開モデルへ置き換えた推論は、元の動画と同じ出力になることを保証しません。

## 時間・画質・フレームの扱い

- 元映像は各視点 128 x 128、20 fps です。AI が推論を待っていた実時間は動画に含まれず、1 action を 1 frame としてシミュレーション時間に沿って保存されています。
- 行動は 20 Hz で実行されました。元の各映像の秒数は `steps / 20` です。動画の再生速度から実際の推論速度を主張しないでください。
- 元映像には生のカメラ観測を 180 度回転して見やすくしたものが保存されています。推論入力の画像を編集したものではありません。
- 各 frame は行動直前の画像です。最後の行動の結果は成功ログに記録されていても、最後の映像 frame にはまだ映っていない場合があります。
- 出力の拡大・2視点配置・フレームレート変換は編集上の処理です。低解像度の細部を新しく生成する処理は行いません。

## 公開依存と再現の限界

シーン定義とアセットは公開プロジェクトから利用者が用意します。配布されたシミュレータのソースやアセットをこのリポジトリから再配布しません。

- [LIBERO-plus](https://github.com/sylvestf/LIBERO-plus)：元環境の固定コミット `4976dc30028e805ff8094b55501d532c48fec182`。
- [LIBERO](https://github.com/Lifelong-Robot-Learning/LIBERO)：元環境が参照したコミット `8f1084e3132a39270c3a13ebe37270a43ece2a01`。
- [OpenVLA-OFT](https://github.com/moojink/openvla-oft)：公開のモデル実装と導入手順。

物理状態は環境の内部配列です。物理エンジン・シーン・コントローラー・初期化手順が異なると、同じ行動でも異なる軌道になる場合があります。保存した関節角との比較により、単に動画が生成できたことと、軌道が一致したことを区別します。この抽出作業自体では新しい GPU モデル推論や物理再生は実行していません。
